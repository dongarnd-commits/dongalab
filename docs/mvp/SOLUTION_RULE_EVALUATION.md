## 보완한 최소 규칙

- 업무 분류와 동의어를 분리했다. 인사라는 공통 분류가 근태·급여의 상호 제공 근거가 되지 않는다.
- 출퇴근/근태, 급여/임금 등 제한된 표현만 확장한다. 확인·개선·통합 같은 일반 단어만으로 검색 후보를 만들지 않는다.
- 제외·불필요·무관·검토하지 않음 등을 절 단위로 처리한다. 일부 기능 제외와 업무 전체 제외를 구분하며 제외 원문을 한계로 제공한다.
- 자동 원인분석 등의 제외가 현황 조회 전체를 막지 않도록 했다. 원인분석을 제공 가능한 기능으로 추가하지 않는다.
- 요구별 `demand_ids`는 실제 연결 FeatureRevision 명칭·설명에 검색 근거가 있을 때만 부여한다. Capability 이름·홍보 설명만으로 전체 대응을 선언하지 않는다.
- API·DB Schema·Role·State·CONFIRM/ACK/PROPOSABLE·기업 승인·발송 정책은 변경하지 않았다.

## 실제 DOCX/PDF 및 시각 검증

최신 합성 산출물은 개발 Worktree의 일반 테스트 산출물 경로 `test-results/mvp-solution-evaluation-20261030/`에 있다. `synthetic-mvp16.docx`, `synthetic-mvp16.pdf`, `page-1.png`, `page-5.png`이며 Git에서 제외되는 생성물이다. 실제 기업자료는 포함하지 않았다.

PDF는 **5장 모두 A4(약 595×842pt)**다. 16절 제목·동일 검토본문·한글·원천/구조화/제안 Version의 실제 추출을 확인했고 첫/끝 페이지 raster를 열어 배치를 검토했다. 제목이 페이지 마지막에 홀로 남지 않도록 첫 본문과 묶으며, 중복 출처 JSON 출력을 제거했다. DOCX는 실제 편집 가능한 OOXML이고 같은 Version 내용과 원천표를 포함한다. 자동 텍스트·A4·제목 배치 검증은 위 59건에 포함된다.

이전 시각검증의 합성 5장 산출물은 같은 개발 Worktree의 `storage/private/runtime/mvp-solutions-document-review/`에 남아 있다. 이번 평가에서는 그 경로를 갱신하지 않았다. Private Runtime JSON 추가 출력은 자동 승인 검토에서 거부되어 실행하지 않았으며, 이후 일반 `test-results/` 산출물과 콘솔 비교를 사용했다.

## 남은 한계

범용 한국어 의미분석·형태소 분석·실현 가능성 판단이 아니다. 등록된 표현 밖의 동의어, 복잡한 부정/예외, 모순된 범위, 상세 인터페이스 실현성은 사람 검토가 필요하다. 실제 기능 문구에 검색 근거가 부족한 요구는 보수적으로 미대응으로 남으며 일반 Catalog 수동 탐색을 막지 않는다. 이 결과로 공식 자격·기업 Fact·구현범위·원인·사업비·기간·성과·기업 승인이나 발송을 자동 확정하지 않는다.
