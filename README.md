# DongA Lab Shared Project

연구소 구성원이 연구 코드를 함께 개발하고 관리하는 Python 공동 개발 프로젝트입니다.

## 프로젝트 구조

```text
.
├── README.md       # 프로젝트 소개 및 개발 안내
├── .gitignore      # Git 추적 제외 설정
├── src/            # 연구 및 공통 기능 소스 코드
│   └── .gitkeep
└── tests/          # 자동화 테스트
    └── .gitkeep
```

`.gitkeep`은 빈 폴더를 Git에 포함하기 위한 파일입니다. 실제 코드를 추가하면 삭제해도 됩니다.

## 개발 환경 설정

Python 3를 설치하고 프로젝트 루트에서 가상환경을 생성합니다. 공동 실험에 사용할 Python 버전은 팀에서 통일하고 이 문서에 기록합니다.

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

macOS / Linux:

```bash
source .venv/bin/activate
```

현재 별도 외부 의존성은 없습니다. 라이브러리를 도입할 때는 의존성과 버전을 함께 기록하고 설치 방법을 이 문서에 추가합니다.

## 코드 및 테스트 작성

- 연구 코드와 재사용할 기능은 `src/` 아래에 작성합니다.
- 테스트는 `tests/` 아래에 `test_*.py` 이름으로 작성합니다.
- Python 기본 `unittest`를 사용하면 별도 패키지 설치 없이 테스트를 실행할 수 있습니다.
- 패키지를 도입할 때는 `src/<패키지명>/` 구조와 설치 설정을 함께 추가합니다.

프로젝트 루트에서 테스트를 실행합니다.

```bash
python -m unittest discover -s tests -v
```

현재는 초기 폴더 구조만 있으며 테스트 케이스는 없습니다. 테스트 0개로 종료되는 것은 기능 검증을 의미하지 않습니다.

## 공동 개발 원칙

1. 작업 목적을 이슈로 공유하고 `feature/<작업명>` 또는 `fix/<작업명>` 브랜치에서 개발합니다.
2. 변경한 기능에 필요한 테스트와 문서를 함께 작성합니다.
3. Pull Request에 변경 목적, 주요 내용, 테스트 결과를 기록하고 동료 검토 후 병합합니다.
4. 실험을 재현할 수 있도록 데이터 출처, 전처리 방법, 실행 조건, 난수 시드와 환경 버전을 기록합니다.
5. 비밀번호, API 키, 개인정보가 포함된 데이터는 커밋하지 않습니다. 대용량 연구 데이터와 결과물은 팀에서 합의한 저장소에서 관리하고 접근 방법을 문서화합니다.
